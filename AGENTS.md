# datomato-node

Назначение: Сетевой узел: хранение, управление и фоновые задачи.
Перед изменениями читайте README.md, docs/development.md и контекст system из точного SHA задачи через tools/get-context (см. development.md).
Читайте три исходных документа и architecture.md; поздние согласованные решения имеют приоритет.

Меняйте только этот репозиторий в пределах задачи. Исполнитель: отдельная ветка и git worktree.
Не принимайте предложения за решения. Не добавляйте хранилища, криптографию и сетевые
заглушки на этапе 0. Секреты и токены не коммитить. Лицензия не выбрана.
CLI/daemon содержит процессный интерфейс; прикладная логика принадлежит core.
Не зависеть от исходников другого продукта; сетевые DTO не подменяют внутреннюю модель.

Правки контракта: сначала спецификация/векторы contracts, затем фиксация SHA продуктами,
затем проверенное сочетание в system. Временный path не считать самостоятельной сборкой.
Проверка: tools/check; контейнер: tools/container-check. Cargo.lock обязателен.
Итог: изменённое поведение, требования/решения, команды и реальные результаты,
SHA, риски, непройденные проверки и оставшиеся вопросы. Не заявляйте хранение готовым.
